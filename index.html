🛠️ Engine & Technical Architecture

Rendering & Graphics

Dual-buffered 2D canvas for Matrixfall; Three.js WebGL GPU pipeline with 8192×4096 cartographic rasterization and Line2 spherical vector meshes for GeoTrivia.

Procedural Audio

Web Audio API dynamic oscillator sound synthesis across both games with zero external audio assets or audio file dependencies.

Cross-Device Controls

Seamless support for desktop keyboard shortcuts, mouse orbital navigation, and responsive mobile gesture suites (virtual d-pads, touch raycasts, and ergonomic bottom sheets).
